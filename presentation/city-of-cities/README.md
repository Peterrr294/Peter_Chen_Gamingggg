# A City of Cities — Presentation Film

The deliverables of PRESENTATION-01 are:

- **Film:** [A-City-of-Cities.mp4](./A-City-of-Cities.mp4), 75 s, 1920 × 1080, 30 fps, H.264 High, no sound.
- **Cover:** [poster.png](./poster.png), 16:9.
- **Storyboard:** [storyboard.md](./storyboard.md), with stills in [storyboard/](./storyboard/).
- **Settings actually used:** [capture-config.json](./capture-config.json).

This folder only *reads* the project. It imports the unchanged generators and the verified G01 / G02 code from `experiments/`. Nothing in `experiments/` or `scripts/` is modified by it.

## How it is made

1. `index.html` + `film.js` build the real world in the browser:
   - world seed 6201, G01 origins;
   - 30 steps of the verified G02 `WorldGrowthController`;
   - every chunk generated by the existing terrain → network → blocks → parcels → buildings chain, about 110 s.
2. `film.js` renders **each frame from time t** (deterministic, not a screen recording):
   - Three.js orthographic camera;
   - typography drawn on a 2D canvas over the WebGL image.
3. The frames are encoded **in Chrome**:
   - WebCodecs `VideoEncoder` with `avc1.640028`, 8 Mbit/s, keyframe every 2 s;
   - muxed by [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.1.3, loaded from a pinned jsDelivr URL by this page only;
   - **FFmpeg is not installed on this machine**, and nothing was installed for the film.
4. `capture.mjs` (Playwright, already in the project):
   - starts Vite, runs the page and checks that the film's growth history equals the verified G02 record;
   - saves stills, the poster and the MP4;
   - decodes and plays the MP4 in Chrome to verify it (duration, size, playback, decoded frames in `storyboard/decoded-from-mp4/`);
   - writes `capture-config.json`.

## Re-export

```bash
node presentation/city-of-cities/capture.mjs                 # full run: stills, poster, MP4, verification (≈ 3 min: world build ≈ 105 s, encode ≈ 15 s)
node presentation/city-of-cities/capture.mjs --stills-only   # stills + poster only
```

**Requirements:**

- Google Chrome at the default path, or `PLAYWRIGHT_CHROME_PATH`;
- network access to cdn.jsdelivr.net, for the muxer;
- the project's `node_modules` (Vite, three, playwright-core).

The GPU is used when available (the reference run used an RTX 4060 through ANGLE / D3D11, about 54 ms per frame).

**Preview:** with `npm run dev`, open `/presentation/city-of-cities/` and call `await __film.prepare()`, then `__film.renderFrame(seconds)` in the console.

**Optional, if FFmpeg is installed later:** the MP4 is already final. To re-encode it, for example at a lower bitrate:

```bash
ffmpeg -i A-City-of-Cities.mp4 -c:v libx264 -crf 20 -pix_fmt yuv420p -movflags +faststart A-City-of-Cities-small.mp4
```

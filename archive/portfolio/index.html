01 / ABOUT

你好，我是 Peter。我正在学习如何把想法做成真正能玩的游戏，并用清晰的记录保留每一次尝试。

这个网站是我的公开开发档案。它不只展示完成品，也展示功能如何产生、问题如何被发现，以及一次优化为什么有效。

我关注网页游戏、交互设计和视觉体验。目前从 HTML、CSS、JavaScript 与 Three.js 开始，逐步建立属于自己的创作方法。

Starlight Run

MILESTONE 001

从一个想法到可玩的第一版

先完成移动、收集、碰撞和结算四个核心反馈，让游戏尽早进入可测试状态。加入鼠标、触摸与键盘输入，使同一套玩法可以在不同设备上运行。

OPTIMIZATION PLAN

让玩法有层次，而不只是变难

下一阶段会用稀有星屑和连击创造风险回报，再通过分段速度曲线调整节奏。每次只改变一个变量，通过试玩记录判断优化是否有效。

设计原则

先保证反馈清楚，再增加复杂度；先用数据对象扩展规则，再考虑重写结构。

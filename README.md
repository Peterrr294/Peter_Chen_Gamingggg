# React Three Fiber — Basic 3D Scene

A beginner-friendly class assignment built with React, Three.js, React Three Fiber, Drei, and Vite.

## Run locally

```powershell
.\dev.cmd
```

Open the local URL printed in the terminal. Drag to rotate, use the wheel to zoom, and right-drag to pan.

## Production build

```powershell
.\build.cmd
```

The static site is generated in `dist/`.

## Structure

- `src/App.jsx`: Canvas, camera, lighting, grid, and controls
- `src/components/SceneObjects.jsx`: box, sphere, and cylinder
- `src/main.jsx`: React application entry
- `src/style.css`: full-browser layout

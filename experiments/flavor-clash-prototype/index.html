FINITE WORLD / FOUR CULTURAL REGIONS

Four identities.
One shared map.

A controlled prototype for comparing terrain character, local road rules, regional scattering, and routes into a central plaza.

This is a bounded study—not an infinite world and not yet a complete game. Each region owns its seed and parameters so one area can change without silently changing the others.

OPEN SYSTEM NOTES

Local roads: WFC selects compatible road modules inside each region. Boundary constraints leave one controlled exit facing the plaza.

Main route: a Catmull–Rom spline connects the local road component to the central plaza; it is separate from the WFC grid.

Objects: Poisson-disk candidates are filtered by water, slope, and road distance, then rendered with InstancedMesh.

Determinism: the world seed plus a region ID and seed offset produces each region's independent random stream.

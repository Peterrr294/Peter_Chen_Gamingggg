# 2026-10-03 — Timestamped Playwright Evidence for Shader Experiments

## Context

Shader Basics Round 01 already had five implemented experiment modes and a written screenshot plan, but the repository had no repeatable screenshot command. Earlier images were stored in the Obsidian vault, yet the capture process itself was not reproducible and same-name output could overwrite earlier visual states.

## Decision

Use `playwright-core` with an installed Chrome or Edge browser. Keep captures inside the repository vault at `docs/assets/screenshots/`, route them to the Shader learning record, and preserve every meaningful run in a timestamped directory rather than replacing prior evidence.

The automation records visible controls and component state. It does not write the learner's observations or claim personal conclusions.

## Changes

- Added `npm run evidence:shader` and the general `npm run evidence:capture` entry.
- Added `scripts/capture-evidence.mjs` with the `shader-basics` capture manifest.
- Captured Experiments A–D once each and Experiment E in UV, local, world, and screen-coordinate modes.
- Added an automatically managed evidence region to the Shader Round 01 learning document.
- Changed subsequent capture runs to use `docs/assets/screenshots/shader-basics/<capture-id>/` and append a new `Capture Run` section.
- Preserved explicit `Observation to complete after testing` prompts after every automated image.

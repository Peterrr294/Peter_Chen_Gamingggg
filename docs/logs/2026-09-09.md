## Concepts Confirmed by the Learner

- Sixteen segments require seventeen vertices because segment endpoints are shared.
- A 64 × 64 sample map needs 64 × 64 vertices and therefore 63 × 63 PlaneGeometry segments.
- F1 values below a threshold become 1 in Threshold mode.
- Resolution must rebuild PlaneGeometry because it changes vertex count.
- Shaping belongs after raw F1 calculation and before writing the shared display map.

## Current Limitations Found in the Audit

### Required-work risks

1. **Resolution changes the noise domain as well as sampling density.** Sampling currently uses integer coordinates from 0 to `resolution - 1`. Increasing resolution therefore shows a larger noise domain compressed onto the same 10 × 10 plane. A rigorous grid-resolution control should sample a fixed world extent.
2. **The production build excludes the experiment.** The root Vite build outputs only the React entry to `dist/`; it does not output `experiments/cellular-noise/`.
3. **The 2D view shows only binary shaped output.** Raw continuous F1 exists in memory but is not shown as grayscale.
4. **The 3D view is a triangulated wireframe height field.** It is not a square GridHelper display or a voxel map.
5. **The assignment page contains mixed Chinese and English presentation text.**
6. **The panel label still refers to Stage 3 even though Stage 5 is complete.**
7. **The algorithm is parallel-friendly but does not currently run in Web Workers.**

### Optional ideas not implemented

- Layer blending

## Key Concept from the Final Discussion

Cellular Noise already produces intermediate values. The missing terrain variation is caused by binary shaping, not by an inability of Cellular Noise to produce continuous information.

Current behavior:

```text
F1 → Threshold / Invert / Band → 0 or 1 → two possible heights
```

Desired terrain behavior:

```text
F1 → normalize to 0–1 → continuous shaping → Float32 heightMap
                                                  ↙             ↘
                                           grayscale 2D    varied 3D height
```

The instructor's Terrace example quantizes a continuous field into several levels rather than only two. Billow folds a signed noise signal to create rounded ridges. The current Band operation is a binary F1 contour and is not the same as Billow.

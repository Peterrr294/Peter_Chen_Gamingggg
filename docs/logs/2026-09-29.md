## Decisions

- Keep Shader Basics independent under `experiments/shader-basics/` and register it as a Vite page and Game Lab tab.
- Use one `PlaneGeometry` and one `ShaderMaterial` for all five modes.
- Use native HTML controls instead of adding another dependency.
- Pass UV, local position, and world position from the vertex stage; use `gl_FragCoord` for screen coordinates.
- Enforce one-variable-at-a-time comparison in the repeated-grid experiment by disabling non-focused controls.
- Use only a slow CPU-side plane rotation so Pause has a visible purpose without introducing a time-driven shader animation.
- Keep learner observations and screenshot evidence empty rather than inventing results.
- Exclude noise, FBM, lighting, PBR, textures, water, ray marching, terrain materials, WFC, and post-processing from Round 01.
